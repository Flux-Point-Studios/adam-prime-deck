# ADAM PRIME deck

[Open the interactive deck](https://flux-point-studios.github.io/adam-prime-deck/)

A five-slide presentation of ADAM by Flux Point Studios.

## Development

Run npm test, npm run build, then npm start. Open http://127.0.0.1:4178.

Edit the presentation in src/. The build writes the static site to docs/. Commit both source and built output, then push to main. GitHub Pages publishes docs/ automatically.

The deck runs entirely in the browser. It has no runtime backend or package dependencies. Role selection and the spending example are local interactions.
